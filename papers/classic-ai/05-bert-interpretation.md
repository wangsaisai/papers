# 05-bert 解读：拿"完形填空"当练功题，让 AI 双向读句子，全面刷新 NLP 纪录

## 一句话总结

谷歌让 AI 做"完形填空"与"接下文"两项自测题练功，再微调上阵，刷新 11 项 NLP 任务纪录。（38 字）

## 论文要解决的问题

**领域在干什么**：自然语言处理（NLP）中"预训练语言表示"这条路——先在海量无标注文本（如维基百科）上让模型学通用的语言知识，再把学好的模型迁移到具体任务（情感分类、问答、推理等）上，省得每个任务从零学。迁移有两种既有路线（论文引言与 2 节）：**feature-based**（特征式）代表是 ELMo——用预训练模型抽出的上下文词向量当"特征"喂给任务专用模型；**fine-tuning**（微调式）代表是 OpenAI GPT——加一个简单输出层，把预训练的全部参数搬到下游任务上继续训练。

**现有方法的核心缺陷**（论文引言），也是本文的靶子：两条路线**都用"单向语言模型"预训练**——即只让每个词看到它左边的词。GPT 的 Transformer 里每个词只能注意它左边的上下文；ELMo 则是把独立训练的"从左到右"和"从右到左"两个模型的表示浅层拼接。论文论证：这种单向约束对句子级任务不理想（比如判断两句话是否矛盾），对问答这类逐词任务更是"非常有害"（原文：could be very harmful）——因为判断答案词的边界必须同时看到左右两边。

## 核心方法

**整体思路**：还是 Transformer 编码器，但把预训练目标从"单向语言模型"换成两个自监督任务，从而让每一层都能同时利用左右上下文，得到"深度双向"表示；下游任务只需换一个输出层，全部参数端到端微调。

> **类比 1：像"通识教育 + 上岗培训"。** 先不预设工作，在通用教材（海量网页文本）上学语言常识；上岗（具体任务）时只补一节课（加一个输出层），其余本事全部沿用。
> **技术落点**：预训练阶段在无标注文本上用两个任务学习；微调阶段用几万条带标签数据，把已有参数全部继续训练，论文 3.2 节强调微调只需引入极少新参数且"比较便宜"——所有结果单块 Cloud TPU 上 1 小时可复现（SQuAD 模型约 30 分钟达到 Dev F1 91.0，脚注 7）。

**核心贡献 1：Masked LM（掩码语言模型，MLM）预训练目标**。
> **类比 2：像学生做"完形填空"。** 老师把句子里的某些词挖掉，学生根据上下文填空——注意，填空时必须同时看空格的左边和右边。
> **技术落点**：随机遮住 15% 的 token（词元，文本切分后的基本单位），让模型根据双向上下文预测被遮词的原词（3.1 节）。这不是标准语言模型那种"每个词都要预测"，而是只预测被遮的那 15%，因此区别于"重建整个输入"的旧式去噪自编码器。为了缓解"预训练时有 [MASK] 符号、微调时没有"的错配，作者用 80%/10%/10% 混合策略：80% 把词换成 [MASK]（占位符），10% 换成随机词，10% 保持原词（附录 A.1 解释这样逼模型保留每个词的分布式表示）。

**核心贡献 2：NSP（Next Sentence Prediction，下一句预测）**。问答、推理这类任务的基础是"两句话的关系"，而语言模型学不到这一点。做法：把两句拼成一个序列，两句之间放 [SEP]（分隔符），50% 概率第二句是真·下一句（标签 IsNext），50% 是随机句子（标签 NotNext），让模型学"前言后语是否衔接"的二元分类（3.1 节）；训练结束时模型在该任务上准确率达 97-98%（脚注 5）。论文 5.1 节称它对问答和推理任务都非常有用。

**核心贡献 3：统一的任务无关架构**。BERT 把单句或句对都打包成一个 token 序列（头部加 [CLS] 分类标记），输入表示 = 词嵌入 + 段嵌入（标明属于句子 A 还是 B）+ 位置嵌入三者的和（3 节、图 2，WordPiece 词表 3 万）。微调时：句子级任务取 [CLS] 的表示 C 过一个分类层；token 级任务（如问答）取每个位置的表示算起止位置得分。论文强调 self-attention 天然完成了以往"分别编码两句再交叉注意力"的两步工作（3.2 节）——这是第一个不需要大量任务特化架构的微调式模型。

**规模与训练**（3.1 节、附录 A.2）：预训练语料 BooksCorpus（8 亿词）+ 英文维基百科（25 亿词），合计约 33 亿词；关键是用"文档级"语料而非打乱了的句子级语料，才能学到长程连贯文本。BERT_BASE（12 层、隐藏维度 768、12 头、1.1 亿参数，特意与 OpenAI GPT 同规模以便公平对比）用 4 个 Cloud TPU Pod（16 芯片）训练；BERT_LARGE（24 层、1024、16 头、3.4 亿参数）用 16 个 TPU（64 芯片），各训 4 天、100 万步、每步 12.8 万 token（batch 256×512）；前 90% 步骤序列长 128、后 10% 用 512 来学长序列位置编码。

## 实验结果

**GLUE 总评**（4.1 节、表 1）：GLUE 是当时最权威的多任务语言理解基准（含 MNLI 自然语言推理、SST-2 情感分析、CoLA 语法可接受度等 8 项）。BERT_BASE 平均 79.6、BERT_LARGE 82.1（表 1 自算平均，已排除有争议的 WNLI；官方计分口径下 BERT_LARGE 拿 80.5，比 GPT 的 72.8 高 7.7 个绝对百分点——见摘要）。两项都全面超越此前所有系统，平均绝对提升 4.5%（BASE）和 7.0%（LARGE）；最大的单项 MNLI 提升 4.6 个绝对百分点。

**SQuAD v1.1 问答**（4.2 节、表 2）：BERT_LARGE 单模型 Dev F1 90.9；加 TriviaQA 增强后单模型 Test F1 91.8，集成 93.2，比此前排行榜顶级系统高 1.5 F1（摘要口径）。特别值得注意的是：**单个 BERT 模型就超过了当时最强的集成模型**（F1 口径）。

**SQuAD v2.0**（4.3 节、表 3）：该任务允许"段落里没有答案"，更接近现实。BERT_LARGE 单模型 Test 80.0/83.1（EM/F1），比此前最好系统高 5.1 F1（摘要与表 3）。

**SWAG 常识推理**（4.4 节、表 4）：从四选一里选最合理的后续句，BERT_LARGE Dev 86.6 / Test 86.3，比作者基准 ESIM+ELMo 高 27.1 个百分点、比 OpenAI GPT 高 8.3 个百分点。

**NER 命名实体识别**（5.3 节、表 7）：在 CoNLL-2003 上既验证了微调式也验证了特征式用法——BERT_LARGE Dev F1 96.6；而完全冻结 BERT、只用"最后四层拼接"当特征喂给两层 BiLSTM 的特征式方案 Dev 96.1，只比全面微调差 0.3 F1。这证明 BERT 对两种迁移方式都好用。

**消融 1：预训练目标**（5.1 节、表 5，全部用 BERT_BASE 同等条件）：
- 去掉 NSP：QNLI 从 88.4 掉到 84.9（大幅），MNLI 84.4→83.9，SQuAD F1 88.5→87.9——NSP 对句间关系任务确实有用；
- 换成左到右语言模型（LTR & No NSP，即 GPT 式）：全线大跌，MRPC 86.7→77.5、SQuAD 88.5→77.8（最惨）；
- 在 LTR 之上加一个随机初始化的 BiLSTM 补救：SQuAD 回升到 84.9，但**仍明显低于双向的 88.5**——对照组有力地说明：收益大头来自"深度双向性"和两个预训练任务，而不是数据量、输入表示等其它差异（附录 A.4 也专门列了几处 BERT 与 GPT 训练细节差异，并称消融证明多数提升来自预训练目标本身）。

**消融 2：模型规模**（5.2 节、表 6）：从 3 层到 24 层严格单调涨点——即使只有 3600 条训练样本的 MRPC 也持续受益（79.8→87.8，MNLI-m 77.9→86.6）；同时掩码 LM 的困惑度（模型对文本的"不确定程度"，越低越好）从 5.84 降到 3.23。论文称这是首次令人信服地证明"极端规模"在小任务上也大幅有效（此前 ELMo 增大到某规模后不再涨点）。

**附录取证**（附录 C）：MLM 比 LTR 收敛略慢（毕竟每批只预测 15% 的词），但在绝对准确率上几乎立刻反超；预训练 100 万步比 50 万步在 MNLI 上多约 1.0 个百分点；掩码策略消融（表 8）显示微调方式对 80/10/10 的具体配比相当稳健，但纯用 [MASK] 会在特征式 NER 上出问题（94.9→94.0），纯用随机替换则明显更差（MNLI 83.7 vs 84.2）。

## 核心价值与影响

- **技术层面**：把"双向性"从浅层拼接（ELMo）推进到深度联合（每个 token 在每一层同时看左右上下文），并首次证明微调式模型能在大批句级+词级任务上全面超过任务特化架构（论文三条贡献 1-3 节的总结性陈述）。
- **实用层面**：一套预训练权重 + 输出层替换 = 各种任务的 SOTA，且微调一小时级可复现，大大降低了把先进模型用到新任务的门槛；预训练模型和代码开源（github.com/google-research/bert）。
- **启发层面**：5.2 节的"规模即提升"直接预演了后来的"规模化"时代（解读视角：这篇论文之后 NLP 的军备竞赛——更大的模型、更多的数据——基本就是沿着这条曲线往下走）；双向预训练+微调范式成为后续 RoBERTa、ALBERT、ELECTRA、T5 等几乎所有模型的模板。

## 局限与值得思考的问题

- **作者承认的局限**：MLM 制造了预训练/微调错配（[MASK] 在真实文本里不存在），所以要用混合掩码策略缓解；且每批只预测 15% 的词，收敛比标准语言模型慢（附录 C.1）。
- **客观成本**：预训练极其昂贵——BERT_LARGE 需 64 个 TPU 芯片跑 4 天（附录 A.2），当年普通团队难以复现；以及 GLUE 的 WNLI 子集因数据构造问题被排除、统一预测多数类（附录 B.1），说明基准本身的不完美。
- **（解读视角）**：NSP 这个看似巧妙的"前文后语"任务后来被证明价值有限——RoBERTa 等后续工作删掉它反而更好（这与本文 5.1 节的正面结论相反，但属于本文之外的发现）；论文对"一个预训练模型 + 一个输出层"的简洁性有宣传成分，SQuAD 上为了追平排行榜实际上额外用了 TriviaQA 增强数据（4.2 节脚注）；另外 4.1 节正文"平均提升 7.0%"用的是表 1 自算平均，与官方 GLUE 分数 80.5/7.7% 口径不同，读论文时别把两处数字混为一谈。
