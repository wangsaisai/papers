## 摘要（Abstract）

我们展示了使用扩散概率模型（diffusion probabilistic model）获得的高质量图像合成结果。扩散概率模型是一类受非平衡热力学（nonequilibrium thermodynamics）启发而提出的潜变量模型（latent variable model）。我们最好的结果来自在一个加权的变分下界（variational bound）上训练——该下界是根据扩散概率模型与带 Langevin 动力学的去噪分数匹配（denoising score matching）之间的一个新联系设计的。我们的模型天然支持一种渐进式有损解压（progressive lossy decompression）方案，可以解释为自回归解码（autoregressive decoding）的推广。在无条件 CIFAR10 数据集上，我们获得了 9.46 的 Inception score 和最先进的 3.17 的 FID score。在 256x256 LSUN 上，我们的样本质量与 ProgressiveGAN 相当。我们的实现见 https://github.com/hojonathanho/diffusion。

## 1. 引言（Introduction）

各类深度生成模型近来在多种数据模态上都展示了高质量的样本。生成对抗网络（generative adversarial network, GAN）、自回归模型（autoregressive model）、流模型（flow）和变分自编码器（variational autoencoder, VAE）都合成了令人惊艳的图像和音频样本 [14, 27, 3, 58, 38, 25, 10, 32, 44, 57, 26, 33, 45]，基于能量（energy-based）的建模和分数匹配也取得了显著进展，生成了可与 GAN 相媲美的图像 [11, 55]。

图 1：在 CelebA-HQ 256 × 256（左）和无条件 CIFAR10（右）上生成的样本。

本文介绍了扩散概率模型 [53] 的进展。扩散概率模型（为了简洁我们称之为"扩散模型"）是一条用变分推断（variational inference）训练的参数化马尔可夫链，目标是在有限时间内生成与数据匹配的样本。该链的转移被训练为逆转一个扩散过程——扩散过程是一条与采样方向相反、逐步向数据添加噪声直至信号被毁掉的马尔可夫链。当扩散由小量的高斯噪声构成时，将采样链的转移也设为条件高斯分布就足够了，这带来一个特别简单的神经网络参数化。

扩散模型定义简单、训练高效，但据我们所知，此前还没有工作证明它们能够生成高质量的样本。我们证明扩散模型确实能够生成高质量的样本，有时甚至优于其他类型生成模型已发表的结果（第 4 节）。此外，我们证明扩散模型的某种参数化在训练时揭示了与多噪声水平的去噪分数匹配的等价性，在采样时则与退火 Langevin 动力学（annealed Langevin dynamics）等价（3.2 节）[55, 61]。我们使用这种参数化获得了最好的样本质量结果（4.2 节），因此我们认为这一等价关系是我们主要的贡献之一。

尽管样本质量很高，我们的模型在对数似然方面并比不上其他基于似然的模型（不过，我们模型的对数似然确实优于已报道的退火重要性采样（annealed importance sampling）对能量模型和分数匹配的大估计值 [11, 55]）。我们发现，我们模型无损码长（lossless codelength）的大部分被用于描述不可察觉的图像细节（4.3 节）。我们用有损压缩的语言对这一现象进行了更精细的分析，并证明扩散模型的采样过程是一种渐进式解码（progressive decoding），它沿着一种位序（bit ordering）进行，类似于自回归解码，这种位序极大地推广了自回归模型通常所能达到的范围。

## 2. 背景（Background）

扩散模型 [53] 是形如 pθ(x0) := ∫pθ(x0:T)dx1:T 的潜变量模型，其中 x1, ..., xT 是与数据 x0 ∼ q(x0) 同维度的潜变量。联合分布 pθ(x0:T) 被称为逆向过程（reverse process），它被定义为一条从 p(xT) = N(xT; 0, I) 开始、带有学习得到的高斯转移的马尔可夫链：

pθ(x0:T) := p(xT) ∏ᵗ₌₁ᵀ pθ(x(t−1)|x(t)),

扩散模型与其他类型潜变量模型的区别在于，近似后验（approximate posterior）q(x1:T|x0)（称为前向过程（forward process）或扩散过程）被固定为一条按照方差调度（variance schedule）β1, ..., βT 逐步向数据添加高斯噪声的马尔可夫链：

q(x1:T|x0) := ∏ᵗ₌₁ᵀ q(x(t)|x(t−1)),

训练通过优化负对数似然上通常的变分下界来完成：

E[−log pθ(x0)] ≤ E_q[−log (pθ(x0:T)/q(x1:T|x0))] = E_q[−log p(xT) − Σ log(pθ(x(t−1)|x(t))/q(x(t)|x(t−1)))] =: L  (3)

前向过程的方差 βt 可以通过重参数化（reparameterization）[33] 学习，也可以作为超参数保持恒定；逆向过程的表达能力部分由 pθ(x(t−1)|x(t)) 中高斯条件的选择来保证，因为当 βt 很小时，两个过程具有相同的函数形式 [53]。前向过程的一个显著性质是它允许在任何任意时间步 t 以闭式形式采样 xt：使用记号 αt := 1 − βt 和 ᾱt := ∏ᵗ₌ₛ₌₁ αs，我们有

q(xt|x0) = N(xt; √ᾱt x0, (1 − ᾱt)I)  (4)

因此，通过用随机梯度下降优化 L 的随机项，就可以进行高效训练。进一步的改进来自方差缩减，将 L 重写为（3）：

E_q[ D_KL(q(xT|x0) ‖ p(xT)) + Σ_{t>1} D_KL(q(x(t−1)|x(t), x0) ‖ pθ(x(t−1)|x(t))) − log pθ(x0|x1) ]
       └───┘ L_T              └───────────────┘ L_(t−1)          └───────┘ L_0  (5)

（细节见附录 A。项的标注在第 3 节中使用。）式 (5) 用 KL 散度直接将 pθ(x(t−1)|x(t)) 与前向过程后验相比较，后者在以 x0 为条件下是可解的：

q(x(t−1)|x(t), x0) = N(x(t−1); μ̃t(xt, x0), β̃t I),  (6)

其中 μ̃t(xt, x0) := (√ᾱ(t−1) βt/(1 − ᾱt)) x0 + (√αt (1 − ᾱ(t−1))/(1 − ᾱt)) xt 且 β̃t := ((1 − ᾱ(t−1))/(1 − ᾱt)) βt  (7)

因此，式 (5) 中所有 KL 散度都是高斯分布之间的比较，可以用闭式表达式以 Rao-Blackwellized 的方式计算，而不需要高方差的蒙特卡洛估计。

## 3. 扩散模型与去噪自编码器（Diffusion models and denoising autoencoders）

扩散模型看起来可能是一类受限的潜变量模型，但它们在实现上允许大量的自由度。我们必须选择前向过程的方差 βt、模型架构以及逆向过程的高斯分布参数化。为了指导我们的选择，我们建立了扩散模型与去噪分数匹配之间的一个新的显式联系（3.2 节），它引出一个简化的、加权的变分下界目标，用于扩散模型（3.4 节）。最终，我们的模型设计由简单性和实验结果（第 4 节）来论证。我们的讨论按式 (5) 的各项进行组织。

### 3.1 前向过程和 L_T

我们忽略前向过程方差 βt 可通过重参数化学习这一事实，而是把它们固定为常数（细节见第 4 节）。因此，在我们的实现中，近似后验 q 没有可学习的参数，L_T 在训练期间是常数，可以忽略。

### 3.2 逆向过程和 L_(1:T−1)

现在我们讨论我们在 pθ(x(t−1)|x(t)) = N(x(t−1); μθ(xt, t), Σθ(xt, t))（其中 1 < t ≤ T）中的选择。首先，我们把 Σθ(xt, t) 设为 σt²I，即未训练的、与时间相关的常数。实验上，σt² = βt 和 σt² = β̃t = ((1 − ᾱ(t−1))/(1 − ᾱt)) βt 的结果相似。第一个选择对 x0 ∼ N(0, I) 是最优的，第二个选择对 x0 被确定性设置为一个点时是最优的。这两个极端的对应分布是具有逐坐标单位方差的数据的逆向过程熵的上界和下界 [53]。

其次，为了表示均值 μθ(xt, t)，我们基于以下对 L_t 的分析提出一种特定的参数化。对于 pθ(x(t−1)|x(t)) = N(x(t−1); μθ(xt, t), σt²I)，我们可以写出：

L_(t−1) = E_q[ (1/(2σt²)) ‖μ̃t(xt, x0) − μθ(xt, t)‖² ] + C  (8)

其中 C 是不依赖于 θ 的常数。因此我们看到，μθ 最直接的参数化是一个预测 μ̃t（前向过程后验均值）的模型。然而，我们可以进一步展开式 (8)：将式 (4) 重参数化为 xt(x0, ε) = √ᾱt x0 + √(1 − ᾱt) ε（ε ∼ N(0, I)），并应用前向过程后验公式 (7)：

L_(t−1) − C = E_{x0,ε}[ (1/(2σt²)) ‖ μ̃t(xt(x0, ε), (1/√ᾱt)(xt(x0, ε) − √(1 − ᾱt) ε)) − μθ(xt(x0, ε), t) ‖² ]  (9)

= E_{x0,ε}[ (1/(2σt²)) ‖ (1/√αt) xt(x0, ε) − (βt/(√(1 − ᾱt) √αt)) ε − μθ(xt(x0, ε), t) ‖² ]  (10)

算法 1 训练                          算法 2 采样

```
1: repeat                              1: xT ∼ N(0, I)
2:   x0 ∼ q(x0)                        2: for t = T, ..., 1 do
3:   t ∼ Uniform({1, ..., T})          3:   z ∼ N(0, I) 若 t > 1，否则 z = 0
4:   ε ∼ N(0, I)                       4:   x(t−1) = (1/√αt)(xt − (βt/√(1 − ᾱt)) εθ(xt, t)) + σt z
5:   对 ∇θ ‖ε − εθ(√ᾱt x0 + √(1 − ᾱt) ε, t)‖² 取梯度下降步骤
6: until 收敛                           5: end for
                                       6: return x0
```

式 (10) 揭示出，μθ 必须在给定 xt 的情况下预测 (1/√αt)xt − (βt/√(1 − ᾱt)) ε。由于 xt 可以作为模型的输入，我们可以选择参数化

μθ(xt, t) = μ̃t(xt, (1/√ᾱt)(xt − √(1 − ᾱt) εθ(xt))) = (1/√αt)(xt − (βt/√(1 − ᾱt)) εθ(xt, t))  (11)

其中 εθ 是一个旨在从 xt 预测 ε 的函数逼近器。要从 pθ(x(t−1)|x(t)) 采样 x(t−1)，即计算 x(t−1) = (1/√αt)(xt − (βt/√(1 − ᾱt)) εθ(xt, t)) + σt z，其中 z ∼ N(0, I)。完整的采样流程（算法 2）类似于 Langevin 动力学，其中 εθ 是数据密度的学习到的梯度。此外，利用参数化 (11)，式 (10) 简化为：

E_{x0,ε}[ (βt²/(2σt² αt (1 − ᾱt))) ‖ ε − εθ(√ᾱt x0 + √(1 − ᾱt) ε, t) ‖² ]  (12)

这类似于在由 t 索引的多个噪声尺度上的去噪分数匹配 [55]。由于式 (12) 等于类似 Langevin 的逆向过程 (11) 的变分下界的（其中一个项），我们看到，优化一个类似于去噪分数匹配的目标等价于使用变分推断来拟合一条类似于 Langevin 动力学的采样链的有限时间边际。

总之，我们可以训练逆向过程的均值函数逼近器 μθ 来预测 μ̃t，或者通过修改其参数化来训练它预测 ε（还存在预测 x0 的可能性，但我们在实验早期发现这会导致更差的样本质量）。我们已经证明 ε 预测参数化既类似于 Langevin 动力学，又将扩散模型的变分下界简化为一个类似于去噪分数匹配的目标。尽管如此，它只是 pθ(x(t−1)|x(t)) 的另一种参数化，因此我们在第 4 节通过一个对比预测 ε 与预测 μ̃t 的消融实验（ablation）来验证其有效性。

### 3.3 数据缩放、逆向过程解码器和 L_0

我们假设图像数据由 {0, 1, ..., 255} 中的整数线性缩放到 [−1, 1] 组成。这保证了神经网络逆向过程在从标准正态先验 p(xT) 开始的一致缩放的输入上运行。为了获得离散对数似然，我们将逆向过程的最后一项设为由高斯分布 N(x0; μθ(x1, 1), σ1²I) 导出的独立离散解码器：

pθ(x0|x1) = ∏ᵢ₌₁ᵈ ∫_{δ−(x0^i)}^{δ+(x0^i)} N(x; μθ^i(x1, 1), σ1²) dx
δ+(x) = ∞ 若 x = 1, x + 1/255 若 x < 1            δ−(x) = −∞ 若 x = −1, x − 1/255 若 x > −1  (13)

其中 D 是数据维度，上标 i 表示提取单个坐标。（也可以直接加入更强大的解码器，比如条件自回归模型，但我们把它留给未来的工作。）与 VAE 解码器和自回归模型中使用的离散化连续分布类似 [34, 52]，我们这里的选择保证了变分下界是离散数据的无损码长，无需向数据添加噪声或将缩放操作的雅可比矩阵（Jacobian）纳入对数似然。在采样结束时，我们无噪地显示 μθ(x1, 1)。

有了上述定义的逆向过程和解码器，由式 (12) 和 (13) 派生出的各项构成的变分下界明显对 θ 可微，可以用于训练。然而，我们发现，在以下变分下界的变体上进行训练对样本质量有益（且实现更简单）：

L_simple(θ) := E_{t,x0,ε}[ ‖ ε − εθ(√ᾱt x0 + √(1 − ᾱt) ε, t) ‖² ]  (14)

其中 t 在 1 和 T 之间均匀分布。t = 1 的情形对应 L_0，其中离散解码器定义 (13) 中的积分由高斯概率密度函数乘以分箱宽度来近似，忽略 σ1² 和边缘效应。t > 1 的情形对应式 (12) 的无加权版本，类似于 NCSN 去噪分数匹配模型使用的损失加权 [55]。（L_T 不出现，因为前向过程的方差 βt 是固定的。）算法 1 展示了使用这一简化目标的完整训练流程。

由于我们的简化目标 (14) 丢弃了式 (12) 中的权重，它是一个加权的变分下界，与标准变分下界相比强调了重建的不同方面 [18, 22]。特别是，我们在第 4 节中的扩散过程设置会使简化目标降低对应小 t 的损失项的权重。这些项训练网络去噪噪声量非常小的数据，因此降低它们的权重是有益的，这样网络可以专注于更大 t 项上的较难去噪任务。我们将在实验中看到，这种重新加权带来了更好的样本质量。

## 4. 实验（Experiments）

我们在所有实验中设置 T = 1000，以使采样期间所需的神经网络评估次数与之前的工作一致 [53, 55]。我们将前向过程的方差设为从 β1 = 10⁻⁴ 到 βT = 0.02 线性增加的常数。这些常数相对于缩放到 [−1, 1] 的数据而言很小，保证了逆向过程与前向过程近似具有相同的函数形式，同时使 xT 处的信噪比尽可能小（在我们的实验中 L_T = D_KL(q(xT|x0) ‖ N(0, I)) ≈ 10⁻⁵ bits/维度）。

为了表示逆向过程，我们使用一个类似于未掩码 PixelCNN++ [52, 48] 的 U-Net 主干网络，全程使用组归一化（group normalization）[66]。参数跨时间共享，时间通过 Transformer 正弦位置嵌入（sinusoidal position embedding）[60] 指定给网络。我们在 16 × 16 的特征图分辨率上使用自注意力 [63, 60]。细节见附录 B。

在表 2 中，我们展示了逆向过程参数化和训练目标对样本质量的影响（3.2 节）。我们发现，预测 μ̃ 这一基线选项只有在真正的变分下界上训练时才效果好，而在无加权的均方误差（一种类似于式 (14) 的简化目标）上训练时效果不佳。我们还看到，学习逆向过程的方差（通过将参数化的对角 Σθ(xt) 纳入变分下界）会导致训练不稳定，且样本质量比固定方差更差。如我们提出的那样预测 ε，在固定方差的变分下界上训练时与预测 μ̃ 的表现大致相当，但在我们的简化目标上训练时表现好得多。

### 4.3 渐进式编码

表 1 还展示了我们 CIFAR10 模型的码长。训练集与测试集之间的差距最多为每维度 0.03 bits，与其他基于似然的模型报告的差距相当，表明我们的扩散模型没有过拟合（最近邻可视化见附录 D）。不过，尽管我们的无损码长优于已报道的能量模型和使用退火重要性采样的分数匹配的大估计值 [11]，但与文献中其他类型的基于似然的生成模型相比并不具有竞争力 [7]。

既然我们的样本质量仍然很高，我们得出结论：扩散模型具有一种归纳偏置（inductive bias），使它们成为优秀的有损压缩器。将变分下界的项 L1 + ... + L_T 视为码率（rate），将 L_0 视为失真（distortion），我们样本质量最高的 CIFAR10 模型的码率为 1.78 bits/dim，失真为 1.97 bits/dim，在 0 到 255 的尺度上相当于 0.95 的均方根误差。无损码长的一半以上用于描述不可察觉的失真。

渐进式有损压缩 我们可以通过引入一个镜像式 (5) 形式的渐进式有损编码，进一步探究模型的率失真（rate-distortion）行为：见算法 3 和 4，它们假定可以访问某种过程（例如最小随机编码（minimal random coding）[19, 20]），该过程对任意分布 p 和 q 都能以平均约 D_KL(q(x) ‖ p(x)) bits 的代价传输样本 x ∼ q(x)，其中只有 p 在接收端预先可用。当应用于 x0 ∼ q(x0) 时，算法 3 和 4 按顺序传输 xT, ..., x0，总期望码长等于式 (5)。接收端在任何时刻 t 都已完整拥有部分信息 xt，并且可以逐步估计：

x0 ≈ x̂0 = (xt − √(1 − ᾱt) εθ(xt)) / √ᾱt  (15)

这由式 (4) 得出。（随机重建 x0 ∼ pθ(x0|xt) 也是有效的，但我们这里不考虑它，因为它使失真更难评估。）图 5 展示了在 CIFAR10 测试集上得到的率失真图。在每个时刻 t，失真计算为均方根误差 ‖x0 − x̂0‖²/D，码率计算为到时刻 t 为止累计接收到的比特数。在率失真图的低码率区域，失真急剧下降，表明大部分比特确实被分配给了不可察觉的失真。

图 5：无条件 CIFAR10 测试集的率失真随时间的变化。失真以 [0, 255] 尺度上的均方根误差衡量。详见 表 4。

渐进式生成 我们还运行了一个由随机比特渐进式解压给出的渐进式无条件生成过程。换言之，我们在使用算法 2 从逆向过程采样时预测逆向过程的结果 x̂0。图 6 和图 10 展示了逆向过程进行过程中 x̂0 的样本质量。大尺度的图像特征最先出现，细节最后出现。图 7 展示了在各种 t 下、xt 冻结时的随机预测 x0 ∼ pθ(x0|xt)。当 t 较小时，除精细细节外的一切都被保留；当 t 较大时，只有大尺度特征被保留。这些或许是一些概念压缩（conceptual compression）的迹象 [18]。

图 6：无条件 CIFAR10 渐进式生成（x̂0 随时间从左到右）。更多样本和随时间变化的样本质量指标见附录（图 10 和 14）。

与自回归解码的联系 注意变分下界 (5) 可以重写为：

L = D_KL(q(xT) ‖ p(xT)) + E_q[ Σ_{t≥1} D_KL(q(x(t−1)|x(t)) ‖ pθ(x(t−1)|x(t))) ] + H(x0)  (16)

（推导见附录 A。）现在考虑将扩散过程的长度 T 设为数据的维度，定义前向过程使 q(xt|x0) 将所有概率质量放在前 t 个坐标被掩码掉的 x0 上（即 q(xt|x(t−1)) 掩掉第 t 个坐标），将 p(xT) 设为把全部质量放在一张空白图像上，并且，为了论证起见，取 pθ(x(t−1)|x(t)) 为一个完全表达的条件分布。在这些选择下，D_KL(q(xT) ‖ p(xT)) = 0，最小化 D_KL(q(x(t−1)|x(t)) ‖ pθ(x(t−1)|x(t))) 会训练 pθ 原样复制坐标 t+1, ..., T，并在给定坐标 t+1, ..., T 的情况下预测第 t 个坐标。因此，用这种特定的扩散训练 pθ 就是在训练一个自回归模型。

因此，我们可以把高斯扩散模型 (2) 解释为一种自回归模型，它带有一种无法通过重排数据坐标来表达的广义位序。先前的工作表明，这种重排会引入对样本质量有影响的归纳偏置 [38]，因此我们推测高斯扩散起到了类似的作用，而且可能效果更好，因为与掩码噪声相比，向图像添加高斯噪声或许更自然。此外，高斯扩散的长度不限于等于数据维度；例如，我们使用 T = 1000，这小于实验中 32 × 32 × 3 或 256 × 256 × 3 图像的维度。高斯扩散可以做得更短以加速采样，或者做得更长以提升模型表达能力。

### 4.4 插值

我们可以使用 q 作为随机编码器在潜空间中对源图像 x0, x'0 ∼ q(x0) 进行插值：先采样 xt, x't ∼ q(xt|x0)，然后将线性插值的潜变量 x̄t = (1 − λ)x0 + λx'0 通过逆向过程解码到图像空间，即 x̄0 ∼ p(x0|x̄t)。实际上，我们用逆向过程去除对源图像的损坏版本进行线性插值所产生的伪影，如图 8（左）所示。我们对不同的 λ 值固定噪声，使 xt 和 x't 保持不变。图 8（右）展示了原始 CelebA-HQ 256 × 256 图像（t = 500）的插值和重建。逆向过程产生了高质量的重建，以及合理的插值，姿态、肤色、发型、表情和背景等属性平滑变化，但眼镜不变。更大的 t 产生更粗糙、更多样的插值，t = 1000 时产生全新的样本（附录图 9）。

## 5. 相关工作（Related Work）

虽然扩散模型可能与流模型 [9, 46, 10, 32, 5, 16, 23] 和 VAE [33, 47, 37] 相似，但扩散模型的设计使得 q 没有参数，顶层潜变量 xT 与数据 x0 的互信息几乎为零。我们的 ε 预测逆向过程参数化建立了扩散模型与多噪声水平去噪分数匹配的联系，并使用退火 Langevin 动力学进行采样 [55, 56]。然而，扩散模型允许直接评估对数似然，训练过程显式地用变分推断训练 Langevin 动力学采样器（细节见附录 C）。这种联系也有反向的含义：某种加权形式的去噪分数匹配等同于训练一个类似 Langevin 的采样器的变分推断。学习马尔可夫链转移算子的其他方法包括 infusion training [2]、variational walkback [15]、生成随机网络 [1] 以及其他工作 [50, 54, 36, 42, 35, 65]。

通过分数匹配与基于能量的建模之间的已知联系，我们的工作可能对最近的其他基于能量模型的工作有启示 [67–69, 12, 70, 13, 11, 41, 17, 8]。我们的率失真曲线是在一次变分下界评估中随时间计算的，这让人联想到率失真曲线可以在一次退火重要性采样运行中随失真惩罚计算 [24]。我们的渐进式解码论证可以在卷积 DRAW 及相关模型 [18, 40] 中看到，也可能为自回归模型的子尺度排序或采样策略带来更通用的设计 [38, 64]。

## 6. 结论（Conclusion）

我们展示了使用扩散模型生成的高质量图像样本，并发现了扩散模型与以下方面的联系：训练马尔可夫链的变分推断、去噪分数匹配和退火 Langevin 动力学（并由此推广到基于能量的模型）、自回归模型，以及渐进式有损压缩。由于扩散模型似乎对图像数据具有优秀的归纳偏置，我们期待在其他数据模态中以及作为其他类型生成模型和机器学习系统的组成部分来研究它们的效用。

## 更广泛的影响（Broader Impact）

我们在扩散模型上的工作与其他类型深度生成模型的现有工作范围相似，例如提升 GAN、流模型、自回归模型等样本质量的努力。我们的论文代表了使扩散模型成为这类技术家族中通用工具方面的进展，因此它可能会放大生成模型已经（并将）对更广阔世界产生的任何影响。

不幸的是，生成模型有许多众所周知的恶意用途。样本生成技术可以被用来为政治目的制作高知名度人物的假图像和假视频。虽然在软件工具出现之前很久假图像就已经被手工制作，但像我们这样的生成模型使这一过程更容易。幸运的是，CNN 生成的图像目前存在可以被检测出来的细微缺陷 [62]，但生成模型的改进可能会使这一检测变得更加困难。生成模型还反映了它们所训练数据集中存在的偏见。由于许多大型数据集是通过自动化系统从互联网上收集的，因此很难消除这些偏见，尤其是当图像没有标注时。如果在这些数据集上训练的生成模型的样本在互联网上大量传播，这些偏见只会被进一步强化。

另一方面，扩散模型可能对数据压缩有用。随着数据分辨率越来越高、全球互联网流量不断增加，数据压缩对于确保广大受众都能访问互联网可能至关重要。我们的工作可能有助于在无标注原始数据上进行表示学习，服务于从图像分类到强化学习的一系列下游任务；扩散模型也可能在艺术、摄影和音乐领域成为可行的创作工具。

## 附录 A：扩展推导（Extended derivations）

下面是式 (5)（扩散模型方差缩减的变分下界）的推导。该材料来自 Sohl-Dickstein 等人 [53]；我们收录于此仅为完整性。

L = E_q[−log(pθ(x0:T)/q(x1:T|x0))]  (17)

= E_q[−log p(xT) − Σ_{t≥1} log(pθ(x(t−1)|x(t))/q(x(t)|x(t−1)))]  (18)

= E_q[−log p(xT) − Σ_{t>1} log(pθ(x(t−1)|x(t))/q(x(t)|x(t−1))) − log(pθ(x0|x1)/q(x1|x0))]  (19)

= E_q[−log p(xT) − Σ_{t>1} log((pθ(x(t−1)|x(t))/q(x(t−1)|x(t), x0)) · (q(x(t−1)|x0)/q(x(t)|x0))) − log(pθ(x0|x1)/q(x1|x0))]  (20)

= E_q[−log(p(xT)/q(xT|x0)) − Σ_{t>1} log(pθ(x(t−1)|x(t))/q(x(t−1)|x(t), x0)) − log pθ(x0|x1)]  (21)

= E_q[ D_KL(q(xT|x0) ‖ p(xT)) + Σ_{t>1} D_KL(q(x(t−1)|x(t), x0) ‖ pθ(x(t−1)|x(t))) − log pθ(x0|x1) ]  (22)

下面是 L 的另一个版本。它不可解，无法估计，但对我们在 4.3 节中的讨论很有用。

L = E_q[−log p(xT) − Σ_{t≥1} log(pθ(x(t−1)|x(t))/q(x(t)|x(t−1)))]  (23)

= E_q[−log p(xT) − Σ_{t≥1} log((pθ(x(t−1)|x(t))/q(x(t−1)|x(t))) · (q(x(t−1))/q(x(t))))]  (24)

= E_q[−log(p(xT)/q(xT)) − Σ_{t≥1} log(pθ(x(t−1)|x(t))/q(x(t−1)|x(t))) − log q(x0)]  (25)

= D_KL(q(xT) ‖ p(xT)) + E_q[ Σ_{t≥1} D_KL(q(x(t−1)|x(t)) ‖ pθ(x(t−1)|x(t))) ] + H(x0)  (26)

## 附录 B：实验细节（Experimental details）

我们的神经网络架构遵循 PixelCNN++ [52] 的主干，即基于 Wide ResNet [72] 的 U-Net [48]。我们把权重归一化 [49] 替换为组归一化 [66] 以简化实现。我们的 32 × 32 模型使用四个特征图分辨率（32 × 32 到 4 × 4），256 × 256 模型使用六个。所有模型在每个分辨率层级都有两个卷积残差块，并在 16 × 16 分辨率上、卷积块之间放置自注意力块 [6]。扩散时间 t 通过在每个残差块中加入 Transformer 正弦位置嵌入 [60] 来指定。我们的 CIFAR10 模型有 3570 万个参数，LSUN 和 CelebA-HQ 模型有 1.14 亿个参数。我们还通过增加滤波器数量训练了一个更大的 LSUN Bedroom 模型变体，参数约 2.56 亿。

我们使用 TPU v3-8（相当于 8 块 V100 GPU）进行所有实验。我们的 CIFAR 模型在批量大小 128 下以每秒 21 步训练（800k 步训练到完成需要 10.6 小时），采样一批 256 张图像需要 17 秒。我们的 CelebA-HQ/LSUN（256²）模型在批量大小 64 下以每秒 2.2 步训练，采样一批 128 张图像需要 300 秒。我们在 CelebA-HQ 上训练了 0.5M 步，LSUN Bedroom 2.4M 步，LSUN Cat 1.8M 步，LSUN Church 1.2M 步。更大的 LSUN Bedroom 模型训练了 1.15M 步。

除了早期为了让网络规模适应内存限制而做出的超参数初始选择外，我们大部分超参数搜索都是为了优化 CIFAR10 的样本质量，然后把得到的设置迁移到其他数据集：

- 我们从常数、线性和二次调度中选择 βt 调度，所有选项都约束为 L_T ≈ 0。我们不进行扫描就设置 T = 1000，并选择从 β1 = 10⁻⁴ 到 βT = 0.02 的线性调度。
- 我们通过在 {0.1, 0.2, 0.3, 0.4} 上扫描，将 CIFAR10 的 dropout 率设为 0.1。在 CIFAR10 上不使用 dropout 时，我们得到了更差的样本，类似于无正则化 PixelCNN++ [52] 的过拟合伪影。我们在其他数据集上不扫描地将 dropout 率设为零。
- 我们在 CIFAR10 训练期间使用随机水平翻转；我们尝试了有翻转和无翻转两种训练方式，发现翻转能略微提升样本质量。除 LSUN Bedroom 外，我们对所有其他数据集也使用随机水平翻转。
- 在实验初期我们尝试了 Adam [31] 和 RMSProp，并选择了前者。我们将超参数保持为标准值。我们不扫描地将学习率设为 2 × 10⁻⁴，并对 256 × 256 图像将其降低到 2 × 10⁻⁵，因为用更大的学习率训练似乎不稳定。
- 我们将 CIFAR10 的批量大小设为 128，较大图像设为 64。我们没有对这些值进行扫描。
- 我们对模型参数使用衰减因子 0.9999 的 EMA（指数移动平均）。我们没有对该值进行扫描。

最终实验只训练一次，并在整个训练过程中评估样本质量。样本质量分数和对数似然按训练过程中的最小 FID 值报告。在 CIFAR10 上，我们使用 OpenAI [51] 和 TTUR [21] 仓库的原始代码在 50000 个样本上计算 Inception 和 FID score。在 LSUN 上，我们使用 StyleGAN2 [30] 仓库的代码在 50000 个样本上计算 FID score。CIFAR10 和 CelebA-HQ 按 TensorFlow Datasets (https://www.tensorflow.org/datasets) 提供的方式加载，LSUN 使用 StyleGAN 的代码准备。数据集划分（或未划分）与引入其在生成建模语境中使用的论文的标准做法一致。所有细节都可以在源代码发布中找到。

## 附录 C：相关工作讨论（Discussion on related work）

我们的模型架构、前向过程定义和先验与 NCSN [55, 56] 在微妙但重要的方面有所不同，这些差异提升了样本质量；值得注意的是，我们直接训练采样器作为一个潜变量模型，而不是在训练后事后添加。更详细地说：

1. 我们使用带自注意力的 U-Net；NCSN 使用带膨胀卷积的 RefineNet。我们通过在每一层加入 Transformer 正弦位置嵌入来对 t 做条件化，而不是仅在归一化层（NCSNv1）或仅在输出端（v2）条件化。
2. 扩散模型在每个前向过程步骤中缩小数据（按 √(1 − βt) 因子），这样添加噪声时方差不会增长，从而为神经网络逆向过程提供一致缩放的输入。NCSN 省略了这个缩放因子。
3. 与 NCSN 不同，我们的前向过程会破坏信号（D_KL(q(xT|x0) ‖ N(0, I)) ≈ 0），保证先验与 xT 的聚合后验紧密匹配。同样与 NCSN 不同，我们的 βt 非常小，这保证了前向过程可以被一个具有条件高斯分布的马尔可夫链逆转。这两个因素都能防止采样时的分布偏移。
4. 我们类似 Langevin 的采样器的系数（学习率、噪声尺度等）由前向过程中的 βt 严格推导而来。因此，我们的训练流程直接训练采样器在 T 步之后匹配数据分布：它把采样器作为潜变量模型，用变分推断来训练。相比之下，NCSN 的采样器系数是事后手工设定的，其训练流程不保证直接优化采样器的质量指标。

潜结构性与逆向过程随机性 在采样过程中，先验 xT ∼ N(0, I) 和 Langevin 动力学都是随机的。为了理解第二种噪声源的意义，我们针对 CelebA 256 × 256 数据集在给定相同中间潜变量的条件下采样了多张图像。图 7 展示了共享潜变量 xt（t ∈ {1000, 750, 500, 250}）的逆向过程 x0 ∼ pθ(x0|xt) 的多次抽取。为此，我们从先验的一次初始抽取运行一条逆向链。在中间时间步，链条被拆分以采样多张图像。当链在 xT=1000 的先验抽取之后立即拆分时，样本差异显著。然而，当链在更多步骤之后拆分时，样本共享性别、发色、眼镜、饱和度、姿态和面部表情等高层属性。这表明 x750 之类的中间潜变量编码了这些属性，尽管它们是不可察觉的。

由粗到细的插值 图 9 展示了在潜空间插值之前改变扩散步数时，一对源 CelebA 256 × 256 图像之间的插值。增加扩散步数会破坏源图像中更多的结构，而模型在逆向过程中会补全这些结构。这使我们能够同时进行细粒度和粗粒度的插值。在极限情况下，0 步扩散时，插值在像素空间混合源图像。另一方面，在 1000 步扩散之后，源信息丢失，插值成为全新的样本。
